# X 收藏工具 0.3.2

0.3.2 修正：工具列放在完整媒體容器外，避免被固定高度、overflow:hidden 的圖片框裁切隱藏。

0.3.1 修正：擴充貼文媒體辨識，支援沒有特定媒體容器標籤的圖片／影片與沒有時間標籤的媒體連結。支援 display:contents 容器與延遲載入，並在媒體移除時清理工具列。

X 圖片、GIF 與影片分類下載；作者跟隨／封鎖與 Discord 預覽連結。MIT 授權，獨立實作。

## 更新與安裝

更新：將本包中的 `x-picture-tools` 檔案覆蓋原本載入的同一資料夾，在擴充功能頁按「重新載入」，重新整理所有 X 分頁。不要先移除舊插件；維持相同路徑及擴充功能項目，才能保留分類設定與資料夾授權。

首次安裝：解壓縮到固定位置，開啟 brave://extensions、chrome://extensions 或 edge://extensions，啟用開發人員模式，載入未封裝項目並選擇 `x-picture-tools` 資料夾。不要直接選 ZIP。

本版新增 offscreen 權限與 video.twimg.com 存取，用於 X MP4 下載及瀏覽器本機 GIF 轉檔。更新後若瀏覽器提示重新允許插件，檢查權限後再啟用。

## 排版

- 貼文：媒體下方獨立橫排，順序為作者狀態、封鎖、分類下載、DC 分享；保留原始圖片寬度，不遮右側翻頁箭頭，也不占用 X 原生操作列。
- 圖片／影片檢視頁：底部中央橫排，保留兩側翻頁空間；只下載目前媒體。
- 分類太多時可橫向捲動。進度、重複提醒與重試位於工具列下方。
- 設定頁採用黑白灰、細線與藍色重點色。

## 下載與分類

在設定頁新增分類，選擇既有資料夾。最多 20 個分類，可拖曳排序或使用上下移動按鈕。有效設定自動儲存，也保留手動儲存按鈕；名稱空白或快捷鍵衝突時會提示並暫停儲存。

已選資料夾：直接寫入，不走瀏覽器「另存新檔」，也不出現在瀏覽器下載紀錄。授權失效時開啟設定頁，按該分類「重新授權」，再回 X 重試。瀏覽器只提供資料夾名稱，不提供完整路徑。受保護的系統資料夾可能無法授權。

舊版相對路徑分類：仍使用瀏覽器 Downloads 路徑，直到自行選擇既有資料夾。若瀏覽器另外設定每次詢問存檔位置，舊版路徑仍可能詢問；本插件不修改瀏覽器設定。

外層下載整篇原貼文媒體，不包含引用貼文；放大檢視頁只下載目前項目。GIF／影片資訊從 X 已發出的 API 回應讀取，不額外批次查詢。若頁面在插件更新前已載入，請重新整理或重新載入貼文；無法取得原檔時會提示，不把封面圖片假裝成 GIF。

## GIF 與 MP4

X GIF 通常以 MP4 傳送。本版可下載 MP4 原檔，或在本機解碼並轉成真正的動畫 `.gif`。普通影片保留 MP4，不自動轉 GIF。沒有外部轉檔網站，也不需要另裝 FFmpeg。

可選最大寬度 480／720 px 或原尺寸，幀率 10／15／20／30 fps。預設 GIF、最大寬度 720 px、15 fps；保持比例，不放大。GIF 無聲音，最多 256 色，漸層與影片色彩可能有色階，通常比 MP4 大。

轉檔可能較慢：限制 120 秒、原檔 100 MB、輸出 150 MB，以及總畫素處理量；超限時提示縮小或下載 MP4，不會悄悄裁切。轉檔期間保持瀏覽器開啟。

## 進度、重複與重試

下載與 GIF 轉檔顯示狀態，能取得檔案大小時顯示下載百分比。成功關閉檔案／瀏覽器下載完成後才記錄成功，失敗可重試。

重複提醒依媒體、分類目的地、輸出格式與 GIF 尺寸／幀率辨識，可選「仍要下載」「只補未下載」或取消。批次部分失敗後重試會跳過之前成功的項目。關閉重複提醒時允許再次下載。

成功紀錄最多 3,000 個，僅保存媒體與目的地組合的雜湊及時間。紀錄不會檢查檔案是否仍存在；手動刪除檔案後可強制再下載。同名檔案增加序號，不覆蓋。

## 快捷鍵、檔名與備份

快捷鍵可自訂 Alt＋1～9／A～Z，不設預設快捷鍵。不在輸入框或文字編輯區作用，不重複觸發按住的鍵；須滑鼠指向貼文，或正在檢視媒體。瀏覽器／作業系統保留的快捷鍵可能優先處理。

檔名可選 `作者_貼文ID_序號` 或 `下載日期_作者_貼文ID_序號`。序號補兩位數。

匯出設定包含分類名稱、順序、快捷鍵、檔名、GIF 設定與 DC 網域。不包含寫入授權、帳號資訊或下載紀錄。匯入會確認取代設定，重新選取既有資料夾；無效備份不會清空原有設定。

## 作者操作與分享

跟隨狀態未知用問號，不假裝未跟隨。Shift＋點跟隨可透過原生選單查狀態。跟隨／取消、封鎖／解除沿用 X 原生選單與確認流程，保留 X 原生撤銷提示。解除封鎖不會自動重新跟隨。若放大檢視頁找不到原貼文，回貼文外層操作。

DC 分享只複製連結，可選 fixupx.com／fxtwitter.com／vxtwitter.com。預覽由第三方服務提供，取決於貼文公開性與 Discord；插件不發送訊息。

## 權限與相容性

storage 保存設定與下載紀錄；downloads 支援舊版目的地；clipboardWrite 複製分享連結；offscreen 本機轉檔。僅在 x.com／twitter.com 注入，媒體下載只允許 pbs.twimg.com／video.twimg.com。資料夾 handle 保存於擴充功能自己的 IndexedDB，不提供給 X；臨時 GIF Blob 也存在這裡，完成後刪除。程式沒有分析追蹤，不保存 Cookie 或帳號權杖。

使用者此前版本實測正常。本版驗證：Chrome／Brave／Edge 獨立模擬頁面的排版、設定、作者操作、分享、快捷鍵與 MP4→GIF 均通過。Edge 另載入真正的未封裝插件，用本機測試素材驗證 background→offscreen→IndexedDB→沙箱資料夾完整寫入，以及重複紀錄；確認資料夾選擇 API 可用。

以上不是已登入 X 帳號的跨瀏覽器完整實測；X DOM/API 改動仍可能影響功能。Chrome／Edge 至少需要 Chromium 116 對應功能。Firefox 未驗證，不宣稱支援。

Brave 若顯示未提供資料夾介面，檢查 brave://flags/#file-system-access-api 是否有 File System Access API 開關，啟用並重新啟動後再試。不同版本可能不同；本插件不自行更改開關。
